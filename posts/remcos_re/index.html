Remcos: reverse engineering

Information

Recently i started to reverse engineering a remcos, Remcos Windows remote access trojan (RAT) it was sold as a legitimate tool, but now is being used for cybercriminals.


Stage 1: Analyzing a not-so-obfuscated HTM file

The first stage stargs with a simple .HTM file

When we open up the file we can see that it's not heavily obfuscated, it bascially obfuscate the payload by adding a bunch of words between the characters

so we gonna start by removing the substrings sylph and riatas from this portiones variable.

now we have just a hex encoded string, this one we gonna come back later

looking a litte bit further we can see the word riatas being used almost on the entire code, so we gonna remove it

and finally now we have a more readable code, now we can see what the code really does, it first add the hex encoded string into a variable called INTERNAL_DB_CACHE and add it to the Environment path, by using a powershell command, after that it add this powershell command to a startup via WMI.
